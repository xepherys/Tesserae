Tesserae User Guide

A pixel-art and tileset editor where every pixel is a palette reference, so one drawing carries any number of colorways. This guide covers day-to-day operation. It is kept with the source and updated as the application changes.

1. Concepts in one minute

  • Indexed pixels. A painted pixel stores a reference (bank, slot), not a color. Change a slot's color and every pixel that references it repaints.
  • Banks and slots. A bank is a named group of color slots (a ramp of greens, say). Slots are what you paint with.
  • Variants. A variant is a colorway: each slot holds one color per variant. Switch a canvas to Winter and the whole drawing repaints; the pixels do not change.
  • Layers. Indexed layers are the ones you paint on. Freeform (RGBA) layers arrive from PNG and non-indexed Aseprite files and are read-only until converted. Groups hold layers. A variant override repaints part of an indexed layer in chosen variants only.
  • Views. A canvas tab is one view of a document. Two views of the same file can show different variants, zooms and layer visibility, and both stay in step with every edit.
  • Undo. Every change to a document goes through one undo stack: painting, layer edits, palette edits, grid and settings changes. Ctrl+Z and Ctrl+Y.

2. Starting, opening and saving

Tesserae launches with no file open. The documents area offers New and Open…; the File menu has the same and more.

ActionMenuShortcutWhat happens

The native document format is .tess: a zip holding a JSON description and one PNG per layer cel. It is described in Tesserae-File-Format.md beside this guide.

3. The workspace

The window is a menu bar over a docking workspace, with a status bar along the bottom. The center holds the documents area, where each open view is a tab. Around it sit three panels:

PanelDefault placeHolds
ToolsTop of the left columnThe tool buttons and, below them, the options the active tool uses (brush size and shape, mirroring, fill, contiguous, tolerance).
PaletteLeft columnVariants, banks, slots and the color editor. See Palette.
LayersRight columnThe layer stack of the focused document. See Layers.
TimelineBottomFrames across, pixel layers down, a dot where a layer has pixels at that frame; the transport, the frame edits, this frame's duration and the tags as bars. See Frames and the timeline.
VariantsBottomThe variant wall: the grid cell under the pointer (or a 16 px window around it without a grid), drawn in every variant side by side, titled by the cell's index. It redraws as you paint and as the palette changes, so a stroke made in Spring is seen in Winter and Fire while it is made. Click a tile to show that variant on the canvas.

The status bar

Left to right: the document pixel under the pointer (x, y); its grid cell as cell row,column #index, where the index is row × columns + column, the number the Evocuration tile tools name a cell by; the working layer's pixel there as bank:slot #rrggbbaa in the view's variant (#rrggbbaa alone on a freeform layer, – where nothing is painted); then, on the right, the focused view's variant, its zoom, and the active tool. The pointer fields clear when the pointer leaves the canvas.

Arranging panels

  • Drag a panel's tab to dock it elsewhere, to stack it with another panel, or out of the window to float it. A floating window is titled by what it holds (Palette + Layers) and stays above the main window. Several panels can share one floating window.
  • Close a panel with its ✕; it is hidden, not lost. View ▸ Panels lists every panel and brings a hidden one back where it was.
  • Resize by dragging the splitter between docks. Inside the Palette panel, the bars between Banks, Slots and the color editor resize those sections.
  • Canvas tabs can be dragged into splits and floating windows too. Closing a floating window that holds canvases moves them back to the documents area rather than closing the files.

Layouts

The arrangement is remembered as you change it (a panel floated, docked, closed or moved) and when you quit, and restored next launch, floating windows included, whether or not a file is open. View ▸ Reset Panels returns to the default. View ▸ Save Layout As… stores the current arrangement under a name, and View ▸ Layouts ▸ name applies it.

Views, theme, full screen

  • View ▸ New View of Document (Ctrl+Alt+N) opens a second tab on the same file. Use it to paint in one variant while watching another, or at two zooms.
  • View ▸ Theme switches between Dark and Light; the choice is remembered. Dark takes its grays and its one gold accent from Aseprite's dark theme.
  • View ▸ Pixel Font (on by default) sets the whole interface in the pixel font Pixelify Sans at 16 px, canvas tab titles and panel titles included, drawn the same way everywhere (as the menu dropdowns always were). Off, the interface uses the vector font Inter at 14 px. Remembered; floating panel windows follow.
  • View ▸ Zoom holds the zoom commands and their keys: 1 to 6 for 100 % to 3200 %, Ctrl+0 to fit the whole document in the view, Ctrl++ and Ctrl+− to step. They act on the focused canvas.
  • View ▸ Full Screen (F11) hides the title bar, menu and toolbars. F11 again restores them.
  • View ▸ Show Pixel Grid, Show Grid, Show Cell Status and Show Cell Indices toggle the canvas overlays (see Grid and cell status).
  • View ▸ Tiled Mode repeats the document around itself, on Both Axes, Horizontal only or Vertical only, so a tile's far edge meets its near edge and a seam shows while you paint. The copies fill the space around the canvas and follow every stroke; only the framed one in the middle takes the pointer. Remembered between runs.
  • View ▸ Seam Check marks the edge pixels of every full grid cell that do not meet the pixel across the seam, so a tile that will show a seam is caught before export. Within Cell pairs a cell's left edge with its own right edge and its top with its bottom, as a repeating fill tile meets itself; Between Cells pairs each edge with the next cell over, as cells of one piece laid side by side do. Two pixels meet when their colors are within the Tolerance (10, 20, 35 or 50 % of the Oklab range, the same scale as the shrinkwrap's fuzz) and their alphas within the same share; two transparent pixels always meet, and the document's own edge is never a seam. Judged on the composite the canvas shows, kept in step with every stroke, and drawn in the warning color over the pixels. Needs a grid (§9). Remembered between runs.
  • View ▸ Biome shows the focused view as another biome: As Painted, or one of the biomes the bank names carry under the document's scheme (§10). Every bank of another biome is drawn with the colors of the bank of the same material and recolor in the chosen one, slot by slot by position (gr-f-dirt as gr-dt-dirt), so forest art previews as desert without a pixel changing; banks with no material, or with no counterpart in that biome, draw as painted. The pixels keep their painted banks: painting writes the bank you picked, the eyedropper reads it, and the previews show the biome's colors. View state like the variant, so two views can show two biomes side by side; the status bar says biome dt. A biome the bank names stop carrying (a rename, a changed scheme) falls back to As Painted.
  • View ▸ Onion Skin (F3) ghosts the neighboring frames under the current one (see Frames and the timeline).

Help

The title bar names the build (Tesserae 0.1.0-alpha.1); a report of a problem should quote it.

  • Help ▸ Report a Problem… opens the issue tracker at github.com/xepherys/Tesserae/issues in the browser.
  • Help ▸ Open Logs Folder opens the folder with the application log and any crash bundles (§12), ready to attach to a report.
  • Help ▸ About Tesserae… shows the version, the .NET runtime, the operating system and the logs folder. Copy Details puts those lines on the clipboard for pasting into a report; the other buttons are the two entries above.

Closing the main window quits the application: every floating panel window closes with it.

The brush outline follows the pointer and shows exactly which pixels a pencil, eraser or shape will paint, including the mirrored copies. Shape tools and the lasso preview their result while you drag and commit on release.

Overlays

  • Pixel grid: a line between every pixel. Hidden automatically at low zoom, where it would be noise.
  • Grid: the document's cell grid, when one is set (Grid Settings).
  • Cell status: a small badge in the top-right of each cell that has a status. Badges keep a constant size on screen and hide when cells are too small to hold one.
  • Cell indices: each full grid cell's index, row × columns + column, in its top-left corner. Hidden when cells are narrower than 24 screen pixels.
  • Focus dimming: with focus on (§6), everything outside the focus region under a translucent veil.
  • Seam marks: with the seam check on (§3), the edge pixels that do not meet across a seam, in the warning color.
  • Onion skins: with onion skinning on (§7), the neighboring frames ghosted under the current one.

Messages over the canvas

When a gesture cannot land, the canvas says why rather than doing nothing: painting on a hidden layer (its eye, or a group's above it, is off, so the stroke would land out of sight), on a layer hidden in this view, on a locked layer, on a group, with a bank the layer does not allow, with the shade tool on a freeform layer, or with no layer selected. A paste onto a layer that a bank claims reports pixels that came from other banks; a paste whose colors no slot shows reports how many went into the Pasted bank; a paste with nothing on the clipboard says so. The notice clears when the situation changes.

5. Tools and tool options

Tools live in the Tools panel and the Tools menu. Each has a single-key shortcut (no modifier) that works whenever you are not typing in a text box.

Related tools share one button in the Tools panel, as in Aseprite: Line and Curve; Rectangle and Ellipse; Marquee, Lasso and Magic Wand; Fill and Gradient. A shared button carries a small corner mark and shows the tool chosen last in its block (remembered between runs); a click selects that tool, and holding the button down or right-clicking it opens a menu of the block's tools. A keyboard shortcut or the Tools menu picks any tool directly and the block's button follows.

On an indexed layer every stop is a slot of the active bank, so the gradient never leaves the bank, and a pixel keeps its own alpha (an unpainted one becomes opaque); until you edit the stops it runs through every slot of the bank in order, first at the drag's start and last at its end, so a bank ordered dark to light gives a dark-to-light ramp and dragging the other way reverses it. On a freeform layer the stops are colors. Between two stops the pixels are dithered (or, without dither, hard-stepped on an indexed layer and blended on a freeform one). Each stop owns a band reaching halfway to its neighbors, and the drag runs from the start of the first band to the end of the last, so four slots over a 16-pixel drag give four bands of four pixels rather than a half band at each end; a smooth blend on a freeform layer instead puts the first color exactly at the drag's start and the last at its end. A stroke is one undo step.

6. Selections and moving pixels

Everything in this section works on an indexed layer and on a freeform (RGBA) layer alike. A piece lifted from a freeform layer holds colors and lands as colors; the magic wand on a freeform layer selects the run of one exact color, or, with a tolerance, colors within that distance per channel. Cut and copy from a freeform layer carry colors only, so a paste of them onto an indexed layer matches each color to the slot showing it in the active variant and puts any color the palette lacks in one new bank named Pasted; a paste of indexed pixels onto a freeform layer lands as the colors they showed.

  • Make a selection with the marquee, lasso or wand, or from a path (To selection in the Path tool's options, §5); its outline is drawn as marching ants (alternating light and dark dashes that move), so it reads on any pixels. A click with no drag deselects. Edit ▸ Select All (Ctrl+A) and Deselect (Ctrl+D) do what they say.
  • Edit ▸ Delete (Delete) clears the selected pixels on the working layer.
  • Reshaping a selection. Edit ▸ Invert Selection (Ctrl+I) selects everything else, or everything when nothing is selected. Expand Selection…, Contract Selection… and Border Selection… ask for a number of pixels (the last amount is offered again) and grow the selection outward, shrink it from every edge (the canvas edge counts as an edge), or keep only its own edge that many pixels wide, which is how a sprite's outline is selected from the inside. Growth is square-cornered, as pixel art expects. A selection contracted to nothing goes away. Each is one undo step and puts down a floating piece first.
  • Focus. Edit ▸ Focus on Selection (Ctrl+Shift+F, or the Focus toggle in the Tools panel) takes the selected region as the focus region: the pencil, shade, fill, gradient and shape tools paint only inside it, everything outside it is dimmed, and the region stays when the selection changes or goes away, so the marquee is free for other work while a sprite is worked on. A selection made inside the region narrows painting further; one outside it paints nothing. The same command, the toggle, or Esc with nothing else to back out of, turns it off; Undo also reverses turning it on or off. Focus is part of the document while it is open, like the selection, and is never saved. A canvas resize moves the region with the art.
  • Snap to grid (Shift+S) makes the marquee, the lasso, a move and the arrow-key nudge land on the document grid's lines; Shrinkwrap (a Tools panel option for the marquee and lasso) drops the unpainted pixels from a new selection, and Alt+Shift+S shrinkwraps the one you have. Both are described under tool options (§5).
  • Move. With the Move tool, or by dragging from inside the selection with a selection tool and no modifier, the first drag lifts the selected pixels into a floating piece; later drags move the piece. It stays adjustable until something commits it: Enter, a deselect, switching tool, or saving. Arrow keys nudge it. Esc during a drag abandons that drag. The mask layers (§7) come along: when the piece is lifted, every unlocked mask layer's pixels under the selection are lifted with it, hidden or not, and land where it lands (or go back where they were on a cancel), flipped and rotated with it; one undo step covers the art and the masks. A paste brings no mask pixels.
  • Flip and rotate. Edit ▸ Flip Horizontal (Shift+H), Flip Vertical (Shift+V), Rotate Clockwise (Shift+R) and Rotate Counterclockwise (Alt+Shift+R) turn the selected pixels over or around in place, about the selection's center; a rotation of a non-square selection swaps its width and height around that center (when they differ by an odd amount the top-left corner stays, so rotating back returns exactly). The pixels are lifted into a floating piece if they were not already, so a move can follow, and Enter puts them down; the selection follows the new shape. One undo step. They need a selection or a floating piece.
  • Clipboard. Ctrl+X, Ctrl+C, Ctrl+V cut, copy and paste the selection. A paste arrives as a floating piece you can position before committing. Within the document, pixels keep their bank and slot references. Into another document, or from an RGBA layer, they are matched by color: a color some slot shows in any variant becomes that slot (so a piece copied while Spring showed pastes right while Fire shows), a translucent color becomes the opaque slot of its hue with the alpha kept on the pixel, and a color no variant shows goes into one new bank named Pasted, which undo removes with the paste. The canvas tells you how many colors spilled.
  • Pasting onto another biome's layer. When the layer under the paste has allowed banks (§7) and the piece brings banks they exclude (forest dirt onto a layer that allows only biome=mc), the Map banks dialog opens while the piece still floats. It lists each pasted bank with its pixel count and the bank it will become on this layer, and under it every slot the piece uses with the slot that stands in, each with its swatch. The defaults come from the bank name scheme (§10): a bank becomes the bank of the same material and recolor among the layer's allowed banks (gr-f-dirt becomes gr-mc-dirt), or the one allowed bank when there is only one; slots pair by position, and when the two banks have different slot counts the darkest pairs with the darkest and the lightest with the lightest, the shades between spread proportionally over the slots the BankMap keeps in luminance order. Change any box; keep as pasted leaves that bank (or that slot) exactly as it came. Apply repoints the floating piece as one undo step of its own, so Undo takes back the mapping and leaves the paste; Keep as Pasted closes without changes. Enter then puts the piece down as usual. Edit ▸ Map Banks of Floating Piece… opens the same dialog for any floating piece of references, foreign banks or not, so a piece can be repointed at another bank of its material before it lands.
  • From and to other programs. A copy also puts the colors you saw on the system clipboard as an image, so they paste into Aseprite, an image editor or a chat. Copy in Aseprite (or any program that puts an image on the clipboard) and Ctrl+V here pastes it the same way a piece from an RGBA layer lands: as colors onto an RGBA layer, matched by color onto an indexed layer, with the spill into Pasted announced. Set the working layer first; have a BankMap imported if you want the colors to land in their banks rather than in Pasted. Translucent pixels keep their alpha; an image that only a bitmap format carries arrives opaque. If the clipboard holds no image at all, the canvas says so and nothing happens.

7. Layers

The Layers panel lists the focused document's stack, top-most first. Each row has four columns: the eye (visible in the file), the padlock (locked against editing), a type icon, and the name. Groups indent their children and fold with the arrow before the name.

Paintable with the pencil, eraser, fill and shapes in the Palette panel's paint color (§8); the selection tools, the magic wand, move, cut, copy, paste and delete work on it too (§6). Only the shade tool, which walks a bank's slots, needs an indexed layer. To Indexed turns it into references.
Stencil (a plate with a hole)MaskAn RGBA layer that holds set colors rather than art: a physics mask, a kinds mask, the derived bank and biome masks (§10). Layer Properties makes an RGBA layer a mask and lists its mask colors, one per line as RRGGBB and an optional label (From pixels lists the colors already painted on it); the pencil, fill and shapes then paint only those colors, which the Palette panel offers as swatches, and the gradient refuses the layer. When pixels of any other layer are moved, the mask layers' pixels under them move too, hidden or not (§6).

Selecting, editing, per-view visibility

  • Click a row to make it the working layer of the focused view. Ctrl+click adds rows to the selection for group, convert and delete; the first-selected row stays the working layer, so painting is never ambiguous.
  • Click the eye to hide or show a layer in the file; click the padlock to lock or unlock it. Both are saved.
  • A small swatch before the name is the layer's biome color (§10): its own, or the one it inherits from a group above (the tooltip says which). Layers without one show no swatch.
  • Double-click a row for Layer Properties: name, opacity, locked, allowed banks and biome color (six hex digits, blank for none; the swatch beside the box shows it, and the hint says what a blank inherits). Allowed banks say which banks the layer is meant to hold: terms separated by commas, each a wildcard over the bank name (gr-f-*, *-shadow) or segment=value under the document's bank name scheme (biome=f, material=grass; see §10). The terms are the whole rule: biome=f allows exactly the banks whose biome segment is f, and a bank of the same material in another biome is not allowed unless a term names it. The hint under the box lists every allowed bank. Blank means any bank. While such a layer is the working layer, the Palette panel lists its allowed banks first and dims the rest; the palette's own order (the Bank ▲ ▼ buttons, which RG8 export follows) is unchanged. The allowed banks are enforced at the brush: the pencil, fill and shapes refuse a bank the layer excludes and the canvas says why until an allowed bank is picked (the eraser and the shade tool, which write no bank, are unaffected); the Palette panel dims excluded banks while the layer is the working layer; To Indexed matches the allowed banks first; and a paste that brings other banks onto the layer is pointed out in a notice and offers to map them onto the layer's banks (§6). A bank's own Claims layers setting (§8) still applies to a layer with no allowed banks of its own. For an RGBA layer the dialog also has Mask layer and Mask colors: ticking the box makes it a mask layer (see the Mask row above), the colors box lists what it may be painted in, one per line as RRGGBB and an optional label (applied when the box loses focus), and From pixels fills the list from the colors already painted on the layer and ticks the box. Unticking makes it a plain RGBA layer again; both are undoable.
  • The row's context menu offers Hide in This View and Solo in This View. These change what this canvas shows without touching the file, so a second view of the same document can show everything. Reset This View's Visibility clears them. A view can only ever hide more than the file does, never show a layer the file hides.
  • From the keyboard (the Layer menu): Shift+N and Ctrl+Shift+N add an indexed or an RGBA layer beside the working layer; Page Up and Page Down move the working layer up and down the stack, through groups, over pixel layers only; H solos the working layer in this view, and again shows everything.
  • A hidden layer (its eye off, or a group's above it) cannot be painted: the tools refuse and the canvas says so, since the stroke would land out of sight. Show the layer first.

Frames and the timeline

A document has one or more frames, each with a duration in milliseconds. Every pixel layer holds a cel per frame it has pixels on, as in Aseprite; a frame a layer has no cel at is empty there. The frame a canvas shows is view state, like its variant: two views of one file can sit on two frames, and the frame is never undone. Every tool paints the view's frame; copy, cut, paste, move, flip, rotate and shrinkwrap act on it; a floating piece lands on the frame it was lifted from. The status bar shows frame 2/5 whenever there is more than one.

  • The Timeline panel (bottom): frames across, pixel layers down (top of the stack first), a dot where a layer has a cel, the view's frame lit, the working layer's name in the accent color, and tags as bars over the frame numbers. Click a frame number to show it; click a cell to pick that layer and that frame together. The transport steps and plays; + Frame inserts an empty frame after this one, Duplicate a copy of it, Delete removes it (the last frame stays), and the ms box is this frame's duration (a run of edits is one undo step).
  • The Frame menu and keys. Alt+N new frame, Alt+D duplicate, Alt+Delete delete, , and . previous and next (wrapping), Space play or stop. Frame ▸ Frame Duration… asks for this frame's duration; Frame ▸ Tags… edits the tags.
  • Playback shows each frame for its duration and loops over the tag the starting frame lies in, in that tag's direction (forward, reverse, ping-pong), or over every frame when it lies in none. It stops when you stop it, when the view changes, or when the document drops to one frame.
  • Tags name a range of frames (numbered from 1 in the dialog), with a direction and a repeat count, and are what an exporter will name animations by. Inserting a frame inside a tag grows it; deleting a tag's only frame removes the tag. Imported Aseprite files bring their frames, durations and tags across.
  • Onion skinning (View ▸ Onion Skin, F3, or the Onion toggle in the Timeline panel) ghosts the neighboring frames under the current one: the ◁ and ▷ boxes say how many frames before and after (0 to 4 each), the nearest clearest and each step fainter, and Tint pulls earlier frames toward red and later ones toward blue so the two sides read apart. The ghosts follow every stroke on their frames, the view's variant, biome and visibility, and sit under the current frame so it reads over them. Frames before the first or after the last are simply absent; nothing wraps. All of it is remembered between runs.
  • What still reads frame 1 only: PNG export, RG8 export and the derived bank and biome masks.

8. Palette: variants, banks and slots

The Palette panel has four parts from top to bottom: the variant strip, the Banks list, the Slots grid, and the color editor. Drag the bars between the last three to resize them.

Variants

  • The chips across the top are the document's variants. The highlighted chip is the colorway the focused canvas shows; click another to switch that canvas. The choice is saved with the file as its opening variant.
  • + adds a variant seeded from the active one. Double-click a chip, or use its context menu, to Rename, Move Left, Move Right or Remove.

Banks

  • Each row shows the bank's mask-color swatch, name, slot count, a padlock, and a strip of its colors. Click a row to select the bank; its slots appear below.
  • The filter bar under the header narrows the list as you type. A term is text the name contains (dirt), a wildcard over the whole name (gr-f-*, gr-?-dirt; * any run, ? one character), or a segment of the document's bank name scheme (§10) as biome:f, material:dirt or recolor:deep (= works too, and the value may hold wildcards). Several terms separated by spaces all have to match, so material:dirt biome:dt is one bank. A segment term shows nothing when the document has no scheme or the label is not in it. The caption at the right says how many banks are shown of the total; Esc in the box clears it. The filter is the panel's own and is never saved; the working layer's allowed banks still come first among the banks shown.
  • + adds a bank, − deletes the selected one (its pixels are cleared; Undo brings both back), ▲ ▼ reorder. The context menu has the same plus Properties…, Lock/Unlock, Merge Into…, Split…, Derive Variant Column… and Audit Ramps….
  • Merge Into… moves this bank's slots into another bank you pick: every slot by default (the whole bank merges and, with Remove the bank once every slot has left it checked, the emptied bank goes), or only the slots you tick (a selective merge; the rest stay). Split… moves the slots you tick into a new bank, named in the dialog and placed right after this one. Either way a moved slot keeps its label and colors in every variant, and every pixel painted with it follows to its new bank and slot, so the art does not change; the new bank's slots get fresh ids. The dialog shows what will happen and names any problem (nothing ticked, no other unlocked bank, no name, or a result over 256 slots) before the button lights. One undo step; a locked bank refuses.
  • Derive Variant Column… rebuilds every slot of the bank in the active variant from a reference variant you pick: the reference's lightness steps, slot by slot, in the hues and saturation the active variant already draws (so a Fire column stays lava while taking Spring's shape), with a slot the reference keeps duller staying duller. Keep this variant's darkest and lightest (on by default) stretches the steps over the column's current range; off takes the reference's lightness as it is. The dialog lists every slot before and after; Apply is one undo step.
  • Audit Ramps… reads one variant's column against the other variants and lists the slots that break the ramp: a color used twice in the variant (duplicate), a lightness step that runs the other way from every other variant (out of order), or a slot far from where the other variants put it between its neighbors (outlier). Each finding shows the current color and the color the other variants suggest (the same derivation as a cell's Derive From Other Variants…), with a checkbox; Apply Picked applies the ticked ones as one undo step. Nothing is automatic: an odd color may be deliberate, so every fix is yours to tick. Switch the variant in the dialog to audit another column.
  • Double-click a bank for Bank Properties: name, notes, mask color (six hex digits), Include in wang, Include in rule tiles, the Claims layers setting (None, named layers one per line, or a name pattern) and the lock. Changes apply live.
  • Locking a bank freezes its definition: name, colors, slots and flags refuse changes. Painting with its slots still works. Imported banks start locked.

Slots

  • Each row is a slot: its label, then one color cell per variant. The highlighted cell in the active variant's column is what the pencil paints; the cell with the accent frame is what the editor edits. Clicking a cell in another column edits that slot in that variant without changing what the canvas shows.
  • + adds a slot, − deletes the selected one (pixels cleared, undoable), ▲ ▼ reorder. Ramp… appends a shade ramp built from the editor's color, darkest to lightest, with the number of steps you choose.
  • Double-click a label to rename it in place; Enter applies, Esc cancels.
  • Right-click a cell for Derive From Other Variants…: puts that slot, in that variant, where the other variants put the same slot between its neighbors (the same position along the step from the slot below to the slot above, with the same offset from that line, measured in a perceptual color space), and at the end of a ramp the step the others take from the one neighbor. The dialog shows the current and the derived color; Apply is one undo step. The usual case is a slot that was given a neighbor's color by mistake.

Color editor

The editor edits exactly one cell: the selected slot in the edit variant. It shows a swatch, the caption slot · variant, a hex box and seven sliders: H, S, V, R, G, B and A. Drags coalesce into one undo step per cell. The hex box takes six digits for an opaque color or eight to set alpha, and applies on Enter or when focus leaves. Editing a channel of a fully transparent color makes it opaque. The editor is disabled while the bank is locked.

The color picker. Click the swatch to open it: a small window that edits the same color the editor shows (the selected cell, or the paint color on an RGBA layer) and follows the editor when you select another cell. It has a square, a hue strip, the model's remaining strips and an alpha strip, all live. The model box picks what the strips mean: RGBA (red, green, blue; the square is saturation against value at the hue strip's hue), HSVA, HSLA or Oklab (hue, saturation and lightness in even steps to the eye; saturation runs to the most the screen can show at that lightness and hue, so every point of the square is a real color). The hex box shows the color as RRGGBB or RRGGBBAA, is selectable, applies what you type on Enter, and Copy puts it on the clipboard. Pick is an eyedropper for the whole screen: the pointer shows the color under it and its hex, a click takes it (its alpha stays what the color had), Esc gives up; it reads the screen itself, so another program's window can be sampled. Picking from the screen is available on Windows. Esc closes the picker; every change is undoable as a slider drag is.

Painting a freeform (RGBA) layer

While the working layer is freeform, the panel switches to its paint color: the caption reads Paint color · RGBA layer, the editor's sliders and hex box set the color the pencil, fill and shapes write (the eraser writes transparent), and clicking any slot cell takes that cell's color as the paint color without selecting the slot for painting references. The banks are a swatch book here, not something being edited: the slot buttons are disabled and no bank changes. The eyedropper on a freeform layer picks a color the same way. Painting is undoable per stroke as on an indexed layer, and selecting, moving, cutting, copying and pasting work as they do on an indexed layer (§6).

On a mask layer (§7) the caption reads Paint color · Mask layer and the mask's colors appear as swatches above the editor; clicking one takes it as the paint color. A stroke in a color the mask does not list is refused with the list of its colors; the eraser always works.

9. Grid and cell status

A document can carry a cell grid for tile work. View ▸ Grid Settings… sets the cell width and height and the grid's origin (X, Y, which may be negative so the grid can be offset from the top-left); Remove grid clears it. The grid is drawn when View ▸ Show Grid is on and is saved with the file.

Cell status marks work progress per cell. Hover a cell and press Ctrl+Shift+M (View ▸ Cycle Cell Status) to cycle it: none → WIP → Problem → Complete → none. Badges show when View ▸ Show Cell Status is on. Statuses are saved and are undoable.

Image ▸ Canvas Size… (Ctrl+Shift+R) resizes the document with a nine-way anchor. Every layer, the grid, cell statuses and the selection move with the art, and Undo restores cropped pixels.

10. Document settings, the bank mask layer and the biome mask layer

Image ▸ Document Settings… names the document's bank mask layer. Blank means none. The box suggests the file's RGBA layers as you type; the mouse wheel scrolls the open list. Once a name is set:

  • If no layer of that name exists, a hidden mask layer (§7) is created at the top of the stack; its colors come from the banks, so its mask color list stays empty.
  • After every edit, that layer is recomputed: each position takes the mask color of the bank of the top-most painted indexed pixel there, or transparent where nothing is painted. Hidden art layers still contribute.
  • It is derived data. Anything painted on it is overwritten, and undo and redo keep it in step without extra steps.
  • Naming a layer that already has painted pixels asks first: Overwrite adopts it and recomputes it from the art; Keep as Painted changes nothing. Undoing the adoption restores the painted pixels. The same applies to the biome mask layer below, where the question points at Apply Biome Mask Colors: run that first so the layers carry the colors the mask is derived from, or the derived mask has nothing to show.

This is the mask layer the Aseprite and RG8 pipelines read (the Evocuration masters use Mask_Banks). Tesserae itself does not need it to know a pixel's bank. The setting is saved in the file. The reasoning behind banks, claims and the mask layer is in docs/banks-and-mask-layers.md.

Bank name scheme

The same dialog names the document's bank name scheme: one word per segment of a bank name such as gr-f-dirt-deep, for example set-biome-material-recolor. The words are yours: each labels its segment, and the Banks filter (§8) and a layer's allowed banks (§7) ask for a segment by that label (biome:f, material=grass), so set-biosphere-material-special reads biosphere:f just as well. The separator is the first punctuation character in the template (- here). Two words carry meaning: biome marks the colorway segment, and recolor (last only) a recolor within the material, such as deep, highlight or dead; every other segment is part of the material. The word bank alone is reserved and refused (it means the whole bank); a longer word such as bankset is fine. Each segment is its own thing: material is the material segment and nothing else. Two banks share art, the same drawing recolored, exactly when every segment other than the biome and the recolor agrees; that is the name's art key: under the Evo scheme gr-f-dirt and gr-dt-dirt both have art key gr-dirt, and so do gr-f-grass and gr-f-grass-deep. A name may stop short of the template: a missing trailing segment is simply absent (gr-f-dirt under set-biome-material-special has set gr, biome f, material dirt, no special, art key gr-dirt). Extra trailing segments fold into the recolor when the scheme ends in one (gr-f-cliff-wall-red reads as recolor wall-red), and otherwise join the art key. A special with its own art is its own art key once its name fuses it into the material segment (gr-aw-waterfrozen). As you type, the hint reads the file's first bank name segment by segment under the template's labels and shows its art key; a template that cannot be read disables OK. Blank means the names carry no structure.

The scheme lets a layer's allowed banks be written as biome=f or material=grass (§7), and it travels with the palette: Export BankMap writes it as bankNameScheme and Import BankMap adopts the file's scheme when the document has none, so Tesserae and the XephTools Tile Graph read bank names by one grammar.

Biome mask layer and biome colors

The same dialog names the document's biome mask layer (the Evocuration sheets use Mask_Biomes), derived the way the bank mask is: created hidden if missing, recomputed after every edit, never painted on. Each position takes the biome color of the top-most painted indexed layer that has one; a layer without a biome color (a shadow layer, say) lets the layer beneath it decide, and where no painted layer has one the mask is transparent. A layer's biome color is set in Layer Properties (§7), one biome per layer; a group's biome color is inherited by every layer in it that has none of its own, so coloring the group is enough. The Layers panel shows the color as a swatch before the name. Biome colors and the mask layer's name are saved in the file.

Image ▸ Apply Biome Mask Colors fills the colors in from the layers' allowed banks: every layer or group whose allowed banks say biome=f (one biome, no wildcard) belongs to biome f, and each biome gets one color. A biome keeps the color a layer of it already has; failing that it takes the color painted for it in an existing biome mask layer (the named one, or a layer called Mask_Biomes brought in from Aseprite, read under that biome's painted pixels), so colors a pipeline already expects are kept; failing that it takes the next of a fixed set of twelve distinct colors. Layers that already have a color are left alone. One undo step; the canvas notice counts the biomes and layers colored, or says why nothing was.

Image ▸ Audit Bank Mask compares the painted mask with the art without changing anything: the document's named mask layer, or a layer called Mask_Banks when none is named. For every painted indexed pixel (top-most first) it checks the mask color under it against its bank's, and reports the painted pixels, those with no mask under them, and every group of mismatches by painted color and bank with the grid cells they fall in (row × columns + column). Run it on art converted from Aseprite before naming the mask layer as derived, since naming it overwrites what was painted; the same mask also settles colors that several banks share during To Indexed.

The result is a canvas notice such as BankMap: 12 banks added, 27 overwritten; 169 slots reordered, pixels kept.

The .json carries the bank name scheme and, for a bank whose slots you named, their labels (labels); XephTools reads both, and a slot label becomes the bank's index label there.

Opening a plain .png gives one freeform layer; nothing is guessed into banks. Run To Indexed when ready. Saving as .png flattens the variant the canvas shows.

12. Autosave, recovery and logs

  • Autosave captures every open document every two minutes and whenever the window loses focus, to journals outside your files. Your file on disk is only written by Save.
  • Recovery. If Tesserae did not exit cleanly, the next launch asks Recover unsaved work? and lists what it found. Recovered documents have no path until you Save, which then asks where. Declining discards the journals.
  • Crashes write a bundle with the stack trace and the log tail into the logs folder below (Help ▸ Open Logs Folder). Please attach it when reporting a problem, with the version from Help ▸ About Tesserae….
  • Saves are atomic: the file is written beside the original and swapped in, so an interrupted save cannot leave a half-written document.
